## 四、Gorm 标签规范性问题

### 4.1 标签大小写不一致

**问题**: 部分 Model 使用大写 `Gorm`，部分使用小写 `gorm`

**错误示例** (`system_config.go`, `risk_config.go`):
```go
ConfigKey string `Gorm:"size:64;unique;not null;column:config_key"`
```

**正确示例** (其他大部分文件):
```go
ConfigKey string `gorm:"size:64;unique;not null;column:config_key"`
```

**影响文件**:
- `d:/GoWork/src/zgl/xm/fly-pig-solo/Online ride-hailing/admin-srv/model/system/system_config.go`
- `d:/GoWork/src/zgl/xm/fly-pig-solo/Online ride-hailing/admin-srv/model/system/risk_config.go`

**建议**: 统一使用小写 `gorm`

### 4.2 字段类型不规范

**问题**: `driver_auth.go` 中使用了 `varchar(255)` 而非标准的 `size:255`

```go
Reason string `Gorm:"varchar(255);column:reason"`  // ❌ 错误
Reason string `gorm:"size:255;column:reason"`       // ✅ 正确
```
